The implementation assembles each body's P1 elasticity matrix with NGSolve and eliminates prescribed displacement degrees of freedom. For each normal-contact subset, it enforces the closed normal constraints and solves the remaining tangential friction problem using projected iterations on two-dimensional force disks. It retains states satisfying the normal and tangential laws, advances the relative-displacement history, and accumulates frictional dissipation. Forces are returned in global Cartesian coordinates.

When native arithmetic cannot resolve a contact sign, the implementation reconstructs the same P1 stiffness from the original mesh coordinates and material data and replays the history with increasing precision. Sparse high-precision residual refinement uses a double preconditioner; the nonlinear contact solve stays in the small contact space. Rational linear sticking certificates distinguish exact zero reactions from small nonzero reactions.
